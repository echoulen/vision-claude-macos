A fixed set of macOS keyboard shortcuts — no user customization. Category A (global, state doesn't depend on the cursor) goes into the macOS menu bar — giving the hotkey a visible entry point you can also click with the mouse; Category B (tightly coupled to the current keyboard focus / UI state) stays in the corresponding View's .onKeyPress. Architecture
Adds two FocusedValueKeys: SessionListActions (⌘N/⌘,/⌘1–9) and ChatActions (voice/attach/two menu Bindings).
.commands reads the action via @FocusedValue; if it can't be read, it's disabled.
ModelMenu/PermissionModeMenu's expanded state is lifted from @State to a Binding<Bool>; mouse-click behavior is unchanged.
Deliberately excluded (to avoid scope creep)
✕A fuzzy-search hotkey for the session list — the main screen has no focusable search field.
✕A hotkey to delete the current session — ChatView has no delete entry point, which goes beyond “purely wiring up existing actions”.
✕/mcp and /status panel hotkeys — already fast text commands, so the payoff is low.
