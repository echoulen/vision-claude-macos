vision-claude
visionOS App — Sci-Fi HUD design

Based on the 2026-07-07 UI Brief, with a sci-fi HUD visual direction. 7 screens total, each a Design Component you can open directly in a browser; screen 03 (Chat) includes interactive expand/collapse, slash filtering, permission mode and model menus.

◇ Visual system summary
Sci-fi HUD language
Perspective grid floor, holographic dark panels, corner brackets, scan bands, light trails along execution paths, glowing status orbs — evoking a "cockpit control console" feel.
Color (carried over from EneSense)
Primary blue brightened to holographic blue #5AA9FF; success teal #3EE2C9, warning orange, and error red are brightened in tandem with added glow. Meaning unchanged — it just glows now.
Typography
Monospace (SF Mono / JetBrains Mono) is used extensively for ids, JSON, commands, telemetry numbers, and all-caps microlabels to reinforce the terminal/HUD feel; body copy uses sans.
Motion
Grid advances slowly, scan bands sweep across panels, cards "boot in" one by one, status orbs pulse, sound waves and signal bars tick. Motion stays restrained and never interferes with reading.
01 Session list
App home. Status pill/spine system, boot-in animation, empty state.
02 New session
Two steps: select project → new conversation / resume existing conversation.
03 Chat (core screen) Interactive
Execution trace, permission approvals, permission mode / slash / model menus.
04 Changes (Diff)
Loading / failed / no changes / file list / single-file diff.
05 Settings
Server/Token form + "Pair via browser" entry point.
06 Pairing — web page
Safari/desktop browser page, sci-fi dark web styling.
07 Pairing — app-side confirm
Confirmation card after the deep link is caught, using the app's HUD language.
