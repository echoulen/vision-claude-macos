Cross-Session Relay Cross-Session Messaging · modeled after cmux

Lets one session send a message to another session (it becomes a user message for the recipient). Reuses the existing HUD visual language and semantic colors — no new color semantics; relay messages are distinguished from regular user messages with structural markers (route strip / badge / dashed frame). The screen doesn't distinguish whether the sender is a human or an agent — only the source/target session is labeled.

◇ Design notes
· No new color semantics: relay cards keep the blue user background and are distinguished by structural markers; the unread indicator reuses the existing orange (= needs attention).
· Source-agnostic: whether sent manually by a human or automatically by an agent, the card looks the same — only the source/target session name is shown.
· Busy = queued: when the target is Running, the UI makes clear the message queues and doesn't cut in, so users don't think it interrupts the other side.
· visionOS: the panel uses flat glass, all tappable rows/buttons are ≥60pt, no drag/multi-finger gestures; whether the receiver's card should be left-aligned instead (stronger differentiation) is engineering's call — this draft demonstrates right-aligned + route strip.
