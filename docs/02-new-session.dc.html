◇ Behavior notes
Fuzzy search uses subsequence matching: it hits as long as the typed characters appear "in order" within the project name (e.g. vc matches both vision-claude and vision-claude-server), with matched characters highlighted in blue glow. Clearing the search shows everything. If a project has no existing CLI session in the terminal, the "Resume a conversation" section in STEP 2 doesn't appear.
