Session List SCI-FI HUD · SessionListView.swift

App home — sci-fi HUD edition. Perspective grid floor + holographic panels + corner brackets + scan bands; each session card has a glowing "status spine" and boots in one by one on load. Status semantic colors are still inherited from EneSense.

◇ System reference Status pill + card status spine — shared across the app
Idle Running Waiting Error Open now · ACTIVE Dot color + container glow appear together; the same color extends into a glowing status spine on the card's left edge, so scanning vertically is enough to read status. "Running" breathes, "Waiting" pulses its outer ring. The currently open session (the one whose chat window is open) gets a teal focus ring + corner brackets, orthogonal to the status color — so you can tell "where you are" at a glance.
◇ Git environment Worktree / regular repo + working tree status — card meta row
worktree repo 3 uncommitted clean Worktrees are marked clearly with a teal chip (isolated branch); regular repos use quiet small text. A working tree with uncommitted changes shows an amber "N uncommitted"; a clean one shows a faint "clean".

Layout matches the Permission Card's two-button pattern: the destructive "Delete" uses solid red + glow, "Cancel" stays neutral; the corner brackets and icon pulse carry over the red semantics from the swipe-to-delete area.

◇ Interaction notes
Session cards can be swiped left to reveal "Delete" — a system gesture; this design doesn't render the in-between state. Tapping anywhere on a card opens the conversation. On load, cards and status spines boot in one by one.
⚙ Needs new model fields: SessionMeta.worktree (determines worktree vs. regular repo), GitMeta.dirtyCount (uncommitted file count in the working tree; 0 = clean). A worktree card's cwd should be its own dedicated folder path.
